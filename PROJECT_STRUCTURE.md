# Project Structure

## Core website

- `index.html` — complete project page.
- `styles.css` — full responsive visual system and dark-mode styling.
- `script.js` — smooth in-page navigation behavior.
- `404.html` — fallback page.
- `site.webmanifest` — installable site metadata.
- `robots.txt` — crawler access.
- `.nojekyll` — direct GitHub Pages static serving.

## Style intent

This repo uses a restrained research portfolio style:
- wide whitespace;
- high contrast;
- limited blue + gold accents;
- evidence-forward metric cards;
- minimal animation;
- no decorative 3D;
- readable charts and code blocks.
